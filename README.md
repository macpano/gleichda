# Gleichda – Projektstart

Diesen Ordner als Projektordner verwenden und darin `claude` starten.

- `CLAUDE.md` – liest Claude Code bei jedem Start: Technik, Regeln, Rechtliches
- `docs/konzept.md` – das vollständige Konzept aus dem Chat, die Anforderungen
- `docs/design.md` – Farben, Maße, Schrift, Layoutregeln in Zahlen
- `docs/prompts.md` – Anleitung und die Prompts in der richtigen Reihenfolge
- `assets/` – Logo, App-Icon und die Fahrzeugsymbole als SVG

Anfangen mit `docs/prompts.md`.
